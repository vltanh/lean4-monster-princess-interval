# The princess and monster game on an interval — a Lean formalization

Work in progress: a Lean 4 / Mathlib formalization of S. Alpern, R. Fokkink, R. Lindelauf and
G.-J. Olsder, *The "Princess and Monster" game on an interval*, SIAM J. Control Optim. 47(3)
(2008), 1178–1190, DOI [10.1137/060672054](https://doi.org/10.1137/060672054).

The statements of all the paper's results are in place (`PrincessMonster/`, `Challenge.lean`);
the proofs are being written. This README will be rewritten when the formalization is complete.
