This discovery family changes physical paths and their probabilities, and
separates the **actual maximizing master field**. It does not restrict its new
calendar columns to the proximal field used in lower-bound discovery. The
complete native response oracle periodically adds routes outside the proposed
boundary family. All accepted upper bounds pass the existing exact physical
Qout certificate maker and a separate replay against every Princess.

## Physical search family

The generator includes the exact two-parameter initial-inward routes from
`BOUNDARY_LAYER_KERNEL_AND_GAP.md`, with deficits extending beyond the old
initial gap. It additionally moves the second contact front independently.
For parameters `a,z,d` in physical units, the unnormalized representative has
vertices

```
(0, 1-a)
((z-a)/2, 1-(z+a)/2)
((z+d)/2, 1+(d-z)/2)
(2+d, -1)
(4+d, 1)
```

where `0 <= a <= z < 1` and `-a <= d <= z`. Thus the two fronts are
`W=-1+z` and `U=1+d`. Each actual first endpoint is respected, and the
shared physical normalizer replaces the suffix after the first endpoint or
time two with a direct endpoint tour. The grid parameters are rational,
all physical legs have speed one, and every route visits the center by two.
Direct endpoint tours at every grid start and independent bulk mutations
are also included. This family can change starts, both fronts, calendars,
support probabilities, and the support itself; it is not a fixed-weight
common deformation of the old certificate.

The endpoint kernel only motivates route generation. Clearing this finite
route reservoir is not a Princess security proof. Complete native pricing
is required for any saved bank lower, and its separate continuum transfer
must still be applied. A small upper improvement does not imply an exact
equilibrium or a sufficient finite equilibrium class.

## Run and resume

From the repository root:

```sh
python packages/interval_monster_boundary/test_search.py
python -u packages/interval_monster_boundary/search.py \
  --n 256 --sparse-master --iterations 80 --seconds 3600 --lp-seconds 300 \
  --boundary-points 48 --pricing-paths 256 --full-every 8 --certify-every 4 \
  --seed 577215 --output results/monster-boundary-256
```

The optional sparse event projection reduces the floating master to its
charged nodes. Its monotone extension is priced as an ordinary full nodal
field; its LP objective remains a discovery estimate until physical exact
replay. The full-grid exact verifier currently supplies the certificate
gate. The seed is replayed before optimization, so a solver budget stop
retains a valid upper rather than promoting an unfinished objective.

Add `--resume results/monster-boundary-256/checkpoint.json` to reuse the
calendar bank, random state, and previous best certificate. An older
compatible grid checkpoint can also seed a finer grid by exact path and
calendar lifting; that is a new search trajectory. Each run saves the seed,
options, source hashes, actual CI metadata, solver log, checkpoint, endpoint
diagnostic, and every retained physical certificate. `manifest.json` binds
the output hashes. `BUDGET_STOPPED` records an incomplete search even when
its retained exact certificate remains valid.

The regression checks 1,405 independent rational chronological captures,
including the initial-contact and turn-contact discontinuities, 334 legal
independent-front routes, a small exact all-Princess certificate, and
same-directory resumption without loss of the previous best upper.
